# IanProject Independent 4.0

企业主题可以独立运行。产品、可变规格和购物车使用官方 WooCommerce；两款 IanProject 自制插件均可停用。

## 三个安装包

| 安装包 | 用途 | 是否必须保留 |
| --- | --- | --- |
| ianproject-independent-4.0.0.zip | 页面模板、导航页尾、日常编辑、联系方式、商品展示、基本询价 | 使用本设计时保留 |
| ianproject-tools-1.0.0.zip | 有预览清单的产品资料批量编辑 | 可选，停用后修改结果保留 |
| ianproject-legacy-importer-1.0.0.zip | 扫描、备份、分批转换旧资料和本地图片 | 一次性工具，迁移验收后可删除 |

WooCommerce 是商品和购物车基础，使用这些功能时保持启用。不安装 WooCommerce 仍可使用企业页面、文章、导航、联系方式和基础联系表单；产品区域显示联系入口。

## 全新网站

1. 在「外观 → 主题 → 添加主题 → 上传主题」安装并启用本主题。
2. 需要商品时安装官方 WooCommerce，设置商店币种。不必开通支付。
3. 打开「外观 → IanProject 设置」，点击「创建缺少的基础页面」。只创建页面，不创建旧产品、案例或行业文章。
4. 核对各栏目页面映射。勾选「同时将所选 Home 设为网站首页」后保存。
5. 在「设置 → IanProject 联系方式」核对通用收件邮箱。新增自己的产品、规格、文章和图片。

## 已有旧站升级

先在完整测试副本执行，备份数据库和 wp-content。新主题使用独立目录 `ianproject-independent`，首次安装不要覆盖或提前删除旧的 `ianproject` 主题。

1. 上传并启用新主题，保留旧主题目录和媒体库。已有页面不会自动覆盖，也不会自动切换首页。
2. 单独安装、启用「IanProject 旧资料迁移工具」，在「工具 → IanProject 旧资料迁移」扫描。
3. 检查清单后开始转换。旧产品转为原生 WooCommerce 商品，型号转为原生规格，旧文章转为普通文章，本地旧图复制到媒体库。已识别的页面按栏目映射转为已确认布局，旧正文留备份。
4. 缺图、冲突价格、已有可变商品等会报告并保留待核对，不编造型号价格。补齐后重新扫描、转换。
5. 验收时停用旧的 IanProject 产品目录和网站修复插件，保留 WooCommerce。清空缓存，检查页面、图片、型号、价格、购物车和邮件。
6. 核对并保存页面映射和首页。报告无待核对项目、图片进入媒体库且前台验收通过后，下载报告，再停用或删除迁移工具及旧插件。确认其他资源也没有引用后再删除旧主题。

迁移工具和增强工具互不依赖。删除它们不会删除商品、文章、媒体或迁移备份。

## 日常编辑

| 内容 | 编辑位置 |
| --- | --- |
| 页面文案、图文、模块顺序 | 页面 → 对应页面，原生区块编辑器 |
| Project / Insights | 普通文章，分别使用 Project / Insights 分类 |
| 案例地区、位置、产品范围、材料 | 文章编辑器的 IanProject 信息面板 |
| 工厂、展厅资料 | 外观 → IanProject 设置 → 新增资料草稿；各自为独立子页面 |
| 产品名称、简述、详情大图 | WooCommerce 产品编辑器；正文图片按单列大图插入 |
| 确定单价、商品属性、型号 | WooCommerce 商品数据 → 常规 / 属性 / 可变规格 |
| MOQ、交期、参考价、包装图、定制说明 | 商品数据 → IanProject 资料 |
| 型号图片、包装及补充参数 | 对应可变规格中；主图使用 WooCommerce 原生图片选择器 |
| 产品分类、首页分类图及显示开关 | 产品 → 分类；可隐藏分类及其子分类 |
| About 子页及导航开关 | 外观 → IanProject 设置；隐藏入口不删除内容，完全不公开请设为草稿 |
| 全站通用邮箱 | 设置 → IanProject 联系方式，一处修改 |

产品页顺序：商品属性 → 商品详情 → 包装与交付 → 定制说明 → 其他产品推荐。主图和缩略图使用统一画框，原图不改写；详情图片单列大图显示，可点击放大。

同一代码但尺寸不同会保存成不同规格，购物车不合并。缺少型号照片时沿用系列参考图，不冒充型号实拍。包装图可留空，后续随时添加。

## 价格、购物车及询价

- 确定单价填写 WooCommerce 商品或规格价格，并取消相应「询价商品」选项。参考价填写在 IanProject 资料中，单独保存。
- 原资料只有系列区间价时保留区间，不自动分摊型号单价，不生成虚假零元价格。CNY 资料不自动换成 USD。
- 支持原生购物车及数量修改。当前结算转到 Contact，携带商品、型号、数量和参考金额；不收款、不创建付款订单。
- 产品页不填目的地。Contact 保留 Name、可选 Company website、Country、EXW / FOB / CIF / DDP、Requirements 五项。Requirements 中写清产品、型号、数量和回复邮箱；定制图纸和材料清单通过邮箱发送。
- 表单通过服务器 `wp_mail()` 发到通用邮箱。上线后须实测收件，按主机条件配置邮件发送或 SMTP。本地测试拦截邮件验证逻辑，未验证实际主机投递。
- WooCommerce「即将上线」由站点拥有者控制，主题不会自动公开网站。预览完成后自行决定网站可见性。

## 未来迁移

迁移数据库、`wp-content/uploads`、本主题和 WooCommerce，再用 WordPress 迁移工具更新域名。产品及规格属于 WooCommerce，文章属于 WordPress，图片属于媒体库；无需携带旧资料迁移插件。

仅复制主题不复制商品或文章。默认 CSV 不保证带齐附加图库、包装等全部自定义字段，完整站点迁移更稳妥。切换主题不删除数据，但需要新主题重新安排附加字段的显示。
