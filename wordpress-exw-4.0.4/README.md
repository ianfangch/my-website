# IanProject：EXW 出厂价填写清单与主题 4.0.4

## 价格填写表

`IanProject-EXW-price-input-20261112.xlsx` 包含填写说明、228 条价格填写行、126 个已发布商品概览。另有 UTF-8 CSV 备选。

- 116 个单品各填一条价格，10 个可变系列下的 112 个变体各填一条。系列父商品不重复定价。
- 只需填写黄色的「EXW 单价（USD）」和「计价单位」，适用数量、起订条件和备注可以补充。
- 未确定价格留空，不填写 0 或区间。旧价列只是原网页参考，未确认属于 EXW。
- 原人民币参考资料已明确标注；不会自动换算或把系列最低价分配给所有型号。
- 同型号不同尺寸按变体 ID 分开填写，不改商品 ID、变体 ID。
- 本填写表不是可直接导入的 WooCommerce CSV。回传填写结果后，核对再生成原生价格更新清单。不会将空白单价直接导入清空现有价格。

数据范围为 2026-11-12 通过正式网站公开接口与商品页读取的已发布商品，不包含后台草稿或私有商品。模板里的新价格均为空白，没有编造或自动应用新价格。

## 页面价格说明

Factory price (EXW). Freight, insurance, customs clearance charges, duties, taxes and installation are not included. Final quotation is subject to model, quantity and specifications.

## 主题 4.0.4

本次基于已发布 4.0.2，只处理价格和联系流程。未包含未发布的第二轮图片压缩草稿。

- 列表、详情、购物车、Contact 请求显示 EXW 基础价格及费用排除说明。
- 价格从 WooCommerce 商品或变体原生价格读取；有价格可以加入购物车，未定价规格直接联系询价并携带型号和数量。
- 原自定义参考价、币种、From 和询价价格开关从编辑界面移除；旧资料留存，但不再参与前台单价计算。
- 其他非价格资料尚未删除；其迁移到原生属性和描述需继续核对现有数据。
- 不自动修改现有商品价格或税设置，不导入产品，不发送真实消息、不创建付款订单。

升级前保留文件和数据库备份。在 WordPress「外观 → 主题 → 添加主题 → 上传主题」上传 `ianproject-independent-4.0.4.zip`，选择替换同名主题，然后清除 LiteSpeed 缓存。

升级后没有原生单价的型号显示 Contact，不再显示旧系列参考区间。可以先填好价格表，核对后与价格一起更新。

若开启 WooCommerce 税功能，请将价格录入设为不含税、商店与购物车显示为不含税。网页 EXW 是基础价；Contact 中选择 FOB/CIF/DDP 的请求仍可另行报价。

49 项隔离价格和浏览器检查通过。线上站点及 main 分支均未修改。
