# IanProject 网站修复与联系方式 1.0.3

## 安装一次

1. 下载本分支的 ZIP，不用解压。
2. WordPress 后台 → 插件 → 安装新插件 → 上传插件 → 选择 ZIP → 现在安装 → 启用。
3. 打开 **设置 → IanProject 联系方式**，修改后点击 **保存并同步全站**。

这是小型配套插件，使用当前已安装的 IanProject 主题和图片，不需要重新上传整个主题。需要 WordPress 6.7+、PHP 8.0+。

## 联系方式集中管理

只保留 **一个通用邮箱**，默认 `info@ianproject.com`。如果此前在主题快速设置中保存过自己的询价邮箱，首次安装会保留该自定义值；后续统一在新设置页修改。

可集中修改：通用邮箱、联系电话、WhatsApp、地址/服务区域、地图链接、LinkedIn、Instagram、Facebook、YouTube、Pinterest、TikTok、X。

- 原站所有 sales/info 邮箱展示、邮件按钮和询价表单统一使用通用邮箱；保留邮件主题和正文。
- WhatsApp 按钮和询价表单统一使用设置中的号码；若填了专用 WhatsApp 链接，则优先使用该链接。
- 社交链接留空可隐藏入口。具体嵌入视频和文章里其他公司的地址保持原内容。
- 联系信息在前台显示时统一读取设置，不批量覆盖可编辑区块。原站页面请从这里修改联系方式。
- 保存设置会触发 LiteSpeed 缓存清理。
- 新页面可在简码区块中使用 `[ian_contact field="email"]`、`[ian_contact field="phone"]`、`[ian_contact field="whatsapp" label="WhatsApp"]`、`[ian_contact field="address"]` 或社交字段名。

**请保持插件启用**，联系方式同步与预览导航修复依赖插件运行。

## 随附修复

- 首页卫浴、卧室、家具及 Products 分类配图与说明，使用原主题已有图片。
- 页脚 Standard Products 正确进入产品列表。
- 私密预览时，站内公开页面导航及兼容的 GET 筛选表单保留当前链接中的预览参数；不会把参数加到站外链接、后台、资源文件、REST、POST 表单或购物操作。

分类修复只替换带 `_ian_source` 标记的原站页面中未改动的精确区块片段，并修复当前主题的已保存页脚。用户改过的片段跳过；每个改动页面的原始区块保存在 `_ian_content_backup_1_0_3` 元数据中。主题原始文件不被覆盖；插件不删除页面，不改变首页选择，也不改变即将上线状态。

未内置任何预览密钥、登录信息或第三方账号凭据。启用后请使用自己的预览链接检查网站。
