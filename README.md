# IanProject 产品目录 2.0

独立产品模块，与 IanProject 2.0 主题配套，也能在更换主题后保留产品管理。

WordPress 后台 → 插件 → 安装新插件 → 上传本 ZIP → 启用。启用后在 **产品 → 添加产品 / 产品分类** 创建自己的内容。模块不附带示例产品，也不会自动导入或删除任何产品。

兼容已有 `ian_product`、`ian_product_category`、`_ian_product_data`、`_ian_sku`、`_ian_price_usd`，原站产品会自动继续出现在管理列表中。

产品详情使用原生区块编辑器；目录使用 `[ian_catalog]` 或 `[ian_catalog category="分类别名"]`；价格使用 `[ian_product_price]`。

在旧版 IanProject 主题下可以提前启用本模块，切换到 2.0 主题后自动接管产品功能。若原产品图片仍放在旧主题文件夹，请使用新主题的 **外观 → IanProject 设置 → 迁移并检查旧主题图片**，完成后再删除旧主题。

需要产品功能时保持本模块启用。停用或删除模块不会删除产品数据；更换主题不会删除产品。新建产品请上传图片到媒体库。
