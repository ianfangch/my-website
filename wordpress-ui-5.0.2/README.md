# IanProject 5.0.2 更新

适用于已完成 5.0 数据迁移的网站。此包尚未安装到正式站。

## 本次变化

- 产品卡片更紧凑，固定文字行数、完整价格及底部对齐保留。
- 项目与文章卡片统一图片、文字和入口排版；项目产品／材料资料保留在详情页。
- 项目／文章搜索框加宽，提示不再截断。
- Contact 右侧增加 Our location：小图标、两行地址、Google Maps 链接。地址及联系方式读取全站统一设置，页脚同步使用。

## 安装

1. 保留当前全站备份。WordPress「外观 → 主题 → 安装主题 → 上传主题」，选择 `ianproject-independent-5.0.2.zip`，确认替换已有主题。
2. 「插件 → 安装插件 → 上传插件」，选择 `ianproject-legacy-importer-2.0.2.zip`，替换并启用迁移工具。
3. 「工具 → IanProject 联系页更新」，点预览，核对公司地址和地图，再点「备份并应用联系页及地址更新」。完成后停用迁移工具，并清除 LiteSpeed 页面缓存。

不要运行「旧资料迁移」全量转换。商品、规格、价格、媒体和文章不用重新导入。IanProject Enquiry 1.0.0 及其他现有插件保持原状。
