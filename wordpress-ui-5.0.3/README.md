# IanProject 5.0.3：可选详情页视频

## 安装

视频功能只需要更新主题：外观 → 主题 → 安装主题 → 上传主题，选择 `ianproject-independent-5.0.3.zip` 并替换旧主题，随后清除 LiteSpeed 页面缓存。保留现有询价插件和 WooCommerce，无需重新迁移商品。

本包累积包含 5.0.2 的地址与卡片改动。若之前尚未应用联系页地址，请安装包内未改动的迁移工具 `ianproject-legacy-importer-2.0.2.zip`，到「工具 → IanProject 联系页更新」预览并应用一次，再停用工具。已经应用过则跳过此步，不运行全量旧资料迁移。

## 添加视频

- 商品：产品 → 编辑商品 → 商品长描述。在希望展示的位置，把 YouTube 链接单独放一行，然后更新商品。不要填在短描述或自定义资料中。长描述内 Product details 区域适合商品展示、功能和安装视频；多型号系列可在父商品放通用视频。
- 文章：文章 → 编辑 → 添加原生「YouTube」区块，粘贴链接。区块可放在任意相关段落，支持原生图注。
- 使用区块编辑器编辑商品时，同样可使用原生 YouTube 区块。
- 不需要视频就不添加；已有视频可直接删除对应区块或独立链接，没有额外必填设置。

支持常规 YouTube、youtu.be 分享短链接、Shorts、live 和 embed 视频链接，以及 t / start 起播时间。仅播放列表链接不属于单个视频功能。经典编辑器请保留独立的一行 URL，不要改成普通文字超链接。

视频链接是商品／文章自身内容，不从全站联系方式设置读取。邮箱、电话、WhatsApp、地址和地图继续共用原有设置。

## 展示与速度

- 普通视频 16:9，Shorts 链接 9:16，手机自动适应宽度。
- 初始只展示轻量封面与播放入口，点击才创建 YouTube 隐私增强播放器。页面加载不自动播放。
- YouTube 封面读取失败时回退至本条内容的特色图片；播放器下始终保留 Watch on YouTube 链接，无 JavaScript 时仍可直接打开。
- 缩略图请求可能在点击前发生；点击前不加载 YouTube 播放器及其脚本。
- 不加载 YouTube IFrame API，不新增视频字段或业务插件，不更改价格和询价规则。
- 视频需允许嵌入，浏览器所在网络也需可访问 YouTube；下架、私密或禁止嵌入的视频由 YouTube 提示。

## 验证与预览

自动化检查覆盖原生嵌入、经典编辑器、起播时间、Shorts、多个视频、点击前零播放器请求、键盘操作、手机排版、无脚本备用链接、封面失败回退，以及原购物车／询价／价格和卡片回归。

本测试环境的 YouTube 媒体网络访问受限，因此播放器请求采用拦截验证，未验证实际视频播放。安装后请用允许嵌入的公开视频，在实际访客网络点击播放一次完成验收。

预览图使用本地测试内容及封面回退场景，演示布局；本包未为正式商品或文章填入视频，未修改正式站。原生区块有效性与数据保持结果见 verification.json。
