# IanProject 3.0.1 更新说明

本版修复字体、首页卡片、产品详情和文章图片。没有改动线上站点。

## 已安装 3.0.0 的站点

1. 在「外观 → 主题 → 安装主题 → 上传主题」上传新版主题 ZIP，选择替换已安装的 IanProject 主题。
2. 在「插件 → 安装插件 → 上传插件」上传新版产品模块 ZIP，选择替换已安装版本。确认 WooCommerce 和 IanProject 产品目录都处于“已启用”状态。
3. 清除 LiteSpeed / 主机缓存，再强制刷新浏览器。

**本次覆盖更新即可，不需要重新导入页面或产品。** 新样式和显示修复即时作用于原有内容，不覆盖已编辑的正文、产品、分类和联系方式。

## 本次修复

- 桌面正文统一到 17–18px，手机正文 16px；导航、按钮、说明、页尾同步放大，区块标题约 36–52px。
- 工厂区说明移至标题下方，减少左右分散。
- 首页分类补充缺省简介，保留后台自定义简介；增加“Continuously updated”入口，统一图片和卡片高度。
- 案例卡片统一标题空间和底部信息对齐，产品范围、材料可清楚阅读。
- 导航采用独立的清晰箭头和更大的触控区域，平板显示折叠菜单。
- 产品模块未启用时，主题提供基础产品目录和详情显示，不再依赖 WooCommerce 透明画廊初始化，也不显示购物车入口。完整分类控制与搜索仍需要启用产品模块。
- 产品正文为空但原有元数据中保存型号、尺寸或参数时，使用已保存的信息补充展示，不虚构数据、不修改产品正文。
- 文章旧 Bootstrap 列宽与新网格发生冲突的地方已修正；图片恢复正常宽度，正文和表格使用完整阅读宽度。
- 首页保留目录入口；内页原来的目录索取和配套邮件按钮统一为 Contact，转到联系页面。Contact 页保留表单和实际联系方式。

文章、页面、产品仍使用原生 WordPress / WooCommerce 数据。不要删除 WooCommerce 和产品目录模块；主题的基础显示用于防止模块意外停用时出现空白，并不包含完整目录管理功能。

测试使用本地隔离的 WordPress / WooCommerce 数据与代表性产品资料，没有对线上数据库写入，也没有执行邮件、WhatsApp 或支付操作。
