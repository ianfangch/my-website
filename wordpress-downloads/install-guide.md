# IanProject 3.0 安装与编辑说明

此版本为本地制作的安装包，没有改动线上网站。主题和产品模块分开安装；主题包不含产品数据或样例产品。

## 1. 安装 / 升级

1. 在主机后台备份数据库、uploads 和旧主题。推荐先在测试站执行。
2. WordPress「外观 → 主题 → 安装主题 → 上传主题」，上传 `ianproject-theme-3.0.0.zip`，安装并启用。已安装同名主题时选择更新替换。
3. 需要产品目录时，在「插件 → 安装插件」安装并启用官方 **WooCommerce**，完成国家、币种等基础设置；支付和在线结账不需要开启。再上传并启用 `ianproject-catalog-3.0.0.zip`。已有旧版同名产品模块时更新替换。
4. 打开「外观 → IanProject 设置」，点击 **安装 / 升级已确认整站**，保持页面打开直到显示完成。刷新意外中断时可继续，重复执行会保留之后的人工编辑。
5. 检查首页、导航、Contact 表单及产品图片。若旧站产品仍使用旧主题的图片，点击同页的媒体迁移按钮，完成检查后再删除旧主题。
6. 清除 LiteSpeed / 主机缓存。需要公开网站时，在 WooCommerce 的网站可见性设置中关闭“即将上线”。

只安装主题也可正常使用公司介绍、服务、文章和案例页面；产品栏目会显示联系询价的空目录。产品模块依赖 WooCommerce，请不要在使用产品目录时停用它们。

要求：WordPress 6.7+、PHP 8.0+；WooCommerce 请使用与当前 WordPress / PHP 版本兼容的官方版本。主机上传限制需大于主题 ZIP 的大小。

## 2. 本次整合

- 全站采用同一导航与页尾，包括页面、文章、案例、产品、分类、搜索和 404 页。
- 导航为 Home、Products、Project、Insights、About、Contact。About 文字直接打开 IanProject，旁边箭头打开子页。
- Home 整合企业介绍、工厂与展厅视频、产品类别、定制能力、报价到交付流程及案例。保留空客户评价位置，但前台不展示空评价。
- Project / Insights 使用相同卡片框架，原生文章发布后自动排列到相应页面，支持搜索、筛选、分页。
- About 分为 IanProject、Factory、Showroom、Services。工厂和展厅资料用原生子页面扩展。
- Contact 原正文保留，仅共享表单替换为五项：名字、公司网址（选填）、国家、EXW / FOB / CIF / DDP、Requirements。
- 全站通用邮箱在一处修改；现有 Contact 的其他细节继续保留。

## 3. 日常编辑入口

| 内容 | 后台入口与方法 |
|---|---|
| 首页、公司介绍、服务、联系页 | 页面 → 所有页面 → 编辑，使用 WordPress 区块编辑器 |
| 行业文章 | 文章 → 新增，选择 **Insights** 分类，填写摘要和特色图片后发布 |
| 项目案例 | 文章 → 新增，选择 **Project** 分类，填写案例信息与特色图片后发布 |
| 案例位置、范围、材料等 | 文章编辑器中的 IanProject 信息面板 |
| 产品 | WooCommerce 的「产品 → 所有产品」，编辑标题、SKU、描述、摘要、图片、分类及属性 |
| 产品类别封面 | 产品 → 分类 → 编辑 → 缩略图 |
| 工厂 / 展厅 | 外观 → IanProject 设置 → 新增工厂 / 展厅资料；填写原生页面的国家、城市、地址、类别、特色图片、画廊、视频 |
| 全站邮箱、WhatsApp、地址、社交链接 | 外观 → IanProject 设置 → 统一修改全站联系方式 |
| 栏目显示开关 | 外观 → IanProject 设置 → 导航与栏目显示 |

页面主体可编辑为原生区块；视频链接卡片和公司示意图使用少量自定义 HTML 区块。可在区块编辑器中修改视频链接。不要删除目录、表单和动态列表的 `[ian_...]` 简码。

导航、页尾由主题统一生成，文字链接随栏目显示开关同步；不要单独在某个页面复制一套导航。Logo 可通过 WordPress 站点标识 / 自定义 Logo 设置更换。

## 4. 隐藏的区别

- **导航隐藏**：取消栏目显示，菜单、子导航、相关入口卡片、页尾同步隐藏；页面本身仍可通过原链接打开。
- **暂不公开**：将页面或文章设为草稿 / 私密，访客无法直接访问；未完成的工厂、展厅资料应保存为草稿。
- **产品类别隐藏**：产品 → 分类 → 编辑，勾选隐藏选项；该类别及其子类别从菜单、筛选、目录和首页类别卡片隐藏。产品数据保留，已发布产品的直接链接仍可访问。空类别自动不显示。
- **单个产品**：使用 WooCommerce 原生“目录可见性”。需要直接链接也不公开时，设为草稿 / 私密。

## 5. 迁移与回退

旧行业文章合并为 WordPress 原生文章，旧产品合并为 WooCommerce 原生产品，保留原 ID、发布状态、正文和来源信息。旧分类迁移到原生产品分类。已有无关文章和原生 WooCommerce 产品保留。

页面升级前正文、旧文章和受影响的旧站点模板会留备份。外观 → IanProject 设置可恢复页面升级前备份；产品 → IanProject 目录可单独恢复旧产品。回退会替换对应迁移后的编辑内容，请先另存新编辑。新增页面、文章、媒体不会自动删除。

产品原始币种、价格和型号保留。不使用固定汇率猜测换算：原币种与 WooCommerce 店铺币种不同的产品，先显示询价，请人工核对价格。SKU 冲突会添加 `-IAN-原ID`，原型号仍保留。默认全站为询价目录，不开放购买。

后续迁移到其他主机时，应迁移 **数据库 + uploads + 主题 + 产品模块 + WooCommerce**，再更新站点 URL。单独安装主题会得到布局和可导入的网站内容，不会携带旧站产品或之后新增的业务数据。更换主题也不会删除原生文章、产品和媒体。
