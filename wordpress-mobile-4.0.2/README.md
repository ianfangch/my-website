# IanProject 4.0.2：移动端首屏优化

完整主题更新包，目录仍为 `ianproject-independent`，适用于当前 4.0.1 网站。

## 更新内容

- 手机首页首图由 574,908 字节减至 185,072 字节，约减少 68%；桌面派生图保留原图尺寸 1672×941。
- 原字体转为 WOFF2，字形、字重和排版保留。首页样式请求由 21 次减少到 6 次，原样式顺序保留。
- 首图继续优先加载；下方工厂影片封面延后加载，避免提前下载大原图。
- 修复手机首屏两个按钮重叠，桌面布局保留。
- 商品规格、购物车和联系表单脚本不加入延迟执行。

## 安装

1. 保留当前文件与数据库备份。
2. WordPress「外观 → 主题 → 添加主题 → 上传主题」，上传 `ianproject-independent-4.0.2.zip`，选择用上传主题替换当前同名主题。
3. 以管理员身份打开一次后台仪表盘，自动准备首页首图派生文件。原图、附件记录、产品和正文不会覆盖；不需要重新导入资料或安装新插件。
4. 清除 LiteSpeed 缓存，保留 Basic 预设，再使用 Hostinger 测试手机性能。

派生图片使用服务器的 WordPress 图片引擎，仅处理本地首页图片，保存到 uploads/ianproject-cache。图片引擎不支持 WebP、来源为外站、目录不可写或派生文件丢失时，前台回退原图。访客访问不执行图片生成。修改首页首图后保存页面会重新准备。

## 验证

74 项隔离检查通过，包含原图和正文保护、生成失败回退、桌面排版、手机资源选择、字体、栏目布局、商品规格、购物车到 Contact、邮件及 WhatsApp 草稿、旧链接跳转。测试没有发送真实消息或创建订单。

线上仍需安装后复测，未承诺特定 PageSpeed 分数。此发布未修改线上网站、DNS 或 main 分支。主题 ZIP 内包含完整源码。
