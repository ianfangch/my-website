# IanProject 5.0.0 安装与迁移说明

## 发布内容

| 文件 | 用途 |
| --- | --- |
| ianproject-independent-5.0.0.zip | 网站外观、模板、文章案例、商品展示；安装到「外观 → 主题」 |
| ianproject-enquiry-1.0.0.zip | 当前询价模式的常驻业务插件；安装到「插件」 |
| ianproject-legacy-importer-2.0.0.zip | 一次性转换旧资料；迁移完成验收后可停用 |
| ianproject-tools-2.0.0.zip | 可选原生属性及价格批量编辑工具 |

总压缩包是交付合集，请先解压，再分别上传里面的主题 / 插件 ZIP。不要把总包当作一个主题或插件上传。

## 安装顺序

1. 保留完整网站文件和数据库备份，先在测试副本执行，或安排维护窗口。
2. WooCommerce 保持启用。停止旧版 `ianproject-catalog`、`ianproject-site` 等目录 / 修复插件，避免它们接管前台。新版迁移工具可以识别旧记录，无需旧插件继续运行。
3. 上传并替换同名 IanProject Independent 主题，版本为 5.0.0。上传并启用 IanProject 询价扩展 1.0.0、旧资料迁移工具 2.0.0。已有同名旧迁移工具选择替换。
4. 打开「工具 → IanProject 旧资料迁移」；点击「扫描旧资料」，检查清单，然后「按下方清单转换 / 继续」。这是把正式数据库内容转换为新版的步骤，单纯上传文件不会转换商品。
5. 下载迁移报告。错误项会报告并保留 / 恢复原资料，不能把有错误的项目当作完成；缺少原图时恢复源文件后重试。扫描之后不要同时编辑同一条资料。
6. 在「设置 → IanProject 询价」检查 Contact 页面、通用邮箱和 WhatsApp。原 Contact 中的 `[ian_quote_form]` 保持可用，客户仍通过自己的邮件应用或 WhatsApp 发送。
7. WooCommerce 价格显示后缀沿用你已设置的 EXW。不会覆盖价格、税率、税费录入 / 展示设置或付款方式；没有独立 EXW 配置，也不追加统一费用排除说明。检查不含税录入 / 展示设置与实际报价一致。
8. 清除 LiteSpeed 缓存；检查首页、案例、产品列表、各规格图片、商品详情 / 包装 / 定制、购物车、Contact 草稿和结算跳转。
9. 验收后停用迁移工具；批量工具和图片编辑器按需启用。询价扩展和 WooCommerce 按当前业务保持启用。

## 数据转换规则

- 保留现有商品 ID、规格 ID、原生主图 / 图库及已明确的正数原生价格。
- 不明确单价留空，不用零元，不把系列区间的最低或最高价分配给每个规格，不将人民币参考价自动转换成美元。
- MOQ → Minimum order 属性；交期 → Production lead time 属性；计价单位 → Pricing unit 属性。
- 包装资料 / 图片、定制说明 → 商品描述的原生分组；型号补充参数 / 额外图片 / 包装 → 变体原生描述。
- 型号在不冲突时使用原生 SKU；其他尺寸和参数以原生描述表格保留。
- 案例资料 → 原生正文表格；地区 / 文章主题 → WordPress 原生标签，原有 Project / Insights 分类保留。
- 页面和模板中的旧目录请求、重复 Contact 按钮直接修改源内容，首页目录入口保留；主题不再运行自动按钮替换或去重。
- 业务照片引用转到媒体库，并补齐 WordPress 原生缩略图尺寸。原始图片文件保留。装饰图标、字体等主题资源仍由主题提供。
- 旧字段转移成功后不再作为前台数据源；转换前内容存入迁移备份以供回滚，不因删除工具而自动清除。

## 以后如何编辑商品

使用 WooCommerce 原生常规 / 变量价格、属性、SKU、主图和相册。补充图文直接编辑商品描述和变体描述。

新商品描述可以使用普通 H2 标题 `Product details`、`Packing & delivery`、`Customisation`；主题按这些标题分区。已有迁移分组直接修改其中图文即可。不再填写「IanProject 资料」标签。

不填价格的规格仍可查看图片、规格并通过 Contact 联系。网站没有建立第二套商品、询价单或价格数据库；发送草稿需由客户在邮件 / WhatsApp 中确认发送。

## 独立性与停用

- 停用所有自制工具插件，主题仍能展示基础网站；WooCommerce 提供原生商品和购物车。
- 停用询价扩展会恢复 WooCommerce 原生结算规则，不会自动启用付款方式。当前询价模式需要该扩展保持启用。
- 更换为标准 WooCommerce 主题后，原生商品资料仍可编辑，独立询价扩展继续提供联系草稿、商品 Contact 和结算控制；展示样式随主题改变。
- 删除工具插件不等于删除媒体附件；仍被商品引用的附件不要直接删除。

## 验证范围

本次在隔离副本上转换 196 条来源记录，覆盖 126 个商品、112 个规格及文章 / 页面。88 项流程检查通过；211 段内容中的 1,792 个原生区块校验无效数为 0；802 个原始图片文件哈希一致。

正式网站后台没有写入连接，本发布包未修改线上数据库。实际迁移结果和待处理条数以正式站运行后的报告为准。测试中的示例单价没有导入文件，发布包不会导入或修改为测试价格。
