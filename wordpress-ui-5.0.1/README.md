# IanProject 5.0.1：联系页、购物袋与页脚更新

本次落实四项已确认修改：联系页、购物袋、页脚，以及产品 / 项目 / 文章卡片的固定显示行数。商品、价格、规格和原有询价发送规则保持不变。

- 联系页：整合为需求表单与直接联系入口，Email 打开邮件应用，WhatsApp 打开对话；移除重复邮箱区和装饰照片模块。
- 购物袋：顶部图标入口，空车隐藏角标；使用 WooCommerce 原生数量和 fragments 刷新，手机端常驻。
- 页脚：精简品牌介绍，统一展示邮箱、WhatsApp、所在地及已配置社交渠道。
- 卡片：分类 / 型号 / 地区信息 1 行，标题 2 行，简介 2 行；项目产品和材料各 2 行；价格预留 2 行且不裁切数值；底部入口 / 阅读信息对齐。后台完整内容及搜索资料保留。
- 修正旧按钮清理范围：Contact 页面中的邮件 / WhatsApp 按钮不再被改写为 Contact。

## 安装顺序

1. 保留网站备份。在「外观 → 主题 → 添加主题 → 上传主题」上传 `ianproject-independent-5.0.1.zip`，替换同名主题。
2. 在「插件 → 安装插件 → 上传插件」上传 `ianproject-legacy-importer-2.0.1.zip`，替换原迁移工具并启用。询价扩展继续使用 1.0.0，无需更换。
3. 打开「工具 → IanProject 联系页更新」，先点「预览联系页更新」，再点「备份并应用联系页更新」。这里只更新联系页源内容，不需要重跑全部旧资料或商品迁移。
4. 清除 LiteSpeed 缓存，核对联系按钮、购物袋和页脚。联系页完成验收后，可再次停用迁移工具。

联系页不是由主题临时覆盖，而是写入原生区块内容；以后仍可在页面编辑器修改。更新前会备份并创建修订，更新后若再有人编辑，将停止自动恢复以保护修改。

总压缩包需要先解压，里面的主题 ZIP 和插件 ZIP 分别上传；不要把总包直接作为主题上传。

正式站没有后台写入连接，本包尚未安装到线上。已验证 126 个商品及其规格资料没有被本次联系页更新改变；测试未发送真实邮件或 WhatsApp 消息。
