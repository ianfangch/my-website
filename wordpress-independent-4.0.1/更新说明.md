# IanProject 4.0.1 上线前修正版

本包是对独立主题 4.0.0 的小版本更新。

修复：

1. 联系表单恢复为客户使用自己的邮箱 / WhatsApp 发送，保留五项，附完整复制入口。页面不会自动发信，客户需在邮箱 / WhatsApp 中按 Send。
2. 修复 Materials & finishes 等含特殊字符的文章分类、搜索及翻页链接。
3. 当前询价模式同时限制经典结算和 Store API 结算，不通过网站创建订单；购物车和 Contact 流程保留。
4. 补充旧静态站 .html 链接到现有已发布页面和产品的 301 跳转，方便后续正式域名切换。

安装：先备份；在 WordPress「外观 → 主题 → 添加主题 → 上传主题」上传 ZIP，替换同名的 IanProject Independent，清空 LiteSpeed / CDN 及浏览器缓存。无需重新导入页面、产品或文章，不覆盖数据库中的文字、图片、价格与规格；现有三款可选工具无须更新。

随后在 Contact 填一份示例，分别检查邮箱 / WhatsApp 草稿及复制；自行发送一条测试消息确认能收到。没有默认邮件软件时，可复制到网页邮箱发送。

正式域名另行准备：Hostinger 绑定 ianproject.com 及 www、HTTPS、WordPress 站点地址和旧临时域名引用更新、www 301 归一化、公开访问及收录开关。DNS 变更时保留 Lark 的 MX、SPF 和验证 TXT。切换后复核 robots.txt、WordPress 网站地图、旧 .html 跳转以及购物车到 Contact 的完整流程。

本包不改 DNS，不自动公开网站。已完成 22 项隔离 WordPress 浏览器检查、查询编码回归测试及 2 项询价结算检查，没有向真实客户或企业发送询价。
