# IanProject 图片编辑器 1.0.0

独立可选 WordPress 插件，不依赖 IanProject 主题、WooCommerce 或其他自制插件。停用或删除后，新图片仍保留在媒体库，前台无需此插件。

## 安装和打开

「插件 → 安装插件 → 上传插件」上传 `ianproject-photo-editor-1.0.0.zip` 并启用。

打开「媒体 → IanProject 图片编辑器」，从媒体库或电脑选择图片。媒体列表和附件详情中也有「裁剪并另存新图」链接，点击后在新标签页打开编辑器并载入该图，避免离开尚未保存的产品编辑页面。

## 推荐操作

1. 选择完整原图。白底产品先点「去白边 / 透明边」，检查边界；有目录文字、分隔线的图片再手动裁剪。
2. 通过拖动、边角或 X / Y / 宽 / 高填写裁剪范围；可旋转、翻转、撤销、重做。每张图的裁剪范围和比例分别保留。
3. 水槽等产品选「完整放入画框」，场景照片可选「裁剪填满画框」。用「原图 / 成品预览」随时核对。
4. 主图可用 1600×1200（4:3）、方图 1600×1600、包装 1200×900、缩略图 800×800；也可自定义尺寸。系统提示放大时，缩小输出或换高清原图更清晰。
5. 网页图片推荐 WebP、质量 80–85%；PNG 适合已有透明背景或无损输出；JPEG 适合通用照片。JPEG 不支持透明，会自动改成白底。
6. 填型号、用途、序号和命名规则，例如 `ianproject-{model}-{view}-{index}` 生成 `ianproject-4035t-main-01.webp`。可填写媒体标题和 ALT。ALT 留空会保留媒体库原 ALT；电脑图片没有原 ALT 时留空。
7. 点击「另存到媒体库」或「下载当前图片」。多图可全部另存，或下载一个 ZIP；共用输出尺寸、格式和命名，各图裁剪范围单独保留。重名自动补序号。

另存生成新的附件，不覆盖、重命名或删除原图，也不自动更换商品图片。主图在 WooCommerce「产品图片」替换，型号图在对应「可变规格」中替换，详情图在商品正文里替换。保存后检查前台，必要时清缓存。

## 处理说明

- 裁剪、缩放和编码在浏览器 Canvas 中进行，不调用外部图片服务。选择媒体库图片会读取其原图；仅点击另存才上传导出结果。
- 去白边只是裁掉外围空白，不是抠图。透明选项保留原有透明及画布空白，不会抠除照片里的白底。
- 图片被原文件截掉的部分无法通过裁剪恢复。某些旧水槽文件虽为 1200×1200，但有效内容很小或已截断，应换完整原图；加大像素不会补充细节。
- 图片重新编码后不保留 EXIF / GPS。旋转方向采用浏览器解码后的显示方向。
- 输入 JPEG、PNG、WebP，单张本地文件最大 30 MB、4000 万像素；每批最多 24 张，本地原图合计 150 MB。输出最长边 8192 px，总像素不超过 2400 万，单图最多 20 MB；另存还受主机上传限制。ZIP 合计最多 150 MB。
- 媒体文件来自外部 CDN 且未允许跨域时，浏览器可能无法处理。可先下载原图，再从电脑选择。超大图片建议分批处理。

另有同界面的离线版：下载离线 ZIP、解压，双击 HTML 即可在电脑浏览器使用。离线版只能选本地图片及下载结果；媒体库功能需 WordPress 插件版。

建议使用较新的 Chrome、Edge、Firefox 或 Safari。GPL-2.0-or-later，原图片的权利归属不因编辑而改变。
