## 你需要完成：安装

1. 在 Hostinger 确认全站文件和数据库有可恢复备份，保留目前主题和询价插件 ZIP；有暂存站时先在暂存站替换。
2. 解压总包。到「外观 → 主题 → 安装主题 → 上传主题」，上传 `ianproject-independent-5.0.5.zip`，选择替换当前同名主题。
3. 到「插件 → 安装插件 → 上传插件」，上传 `ianproject-enquiry-1.0.1.zip`，替换现有同名扩展并保持启用；WooCommerce 保持启用。不要安装两个不同目录的询价插件副本。
4. 上传并启用 `ianproject-legacy-importer-2.0.3.zip`，替换原有同名工具。到「工具 → IanProject 商品单位更新」，点击「扫描并预览」，核对列表后点击「备份并应用／继续」。每个商品先备份，再更新计价单位和 MOQ。未知或跨单位分类会跳过并报告。下载报告留存；验收后可停用该工具。**不要重跑「旧资料迁移」或「联系页更新」。**
5. 全站联系方式仍在「设置 → IanProject 联系方式」；WooCommerce 的商店／税务地址独立。以后单位与 MOQ 直接在商品的非变体属性中编辑，无需让工具一直启用。
6. 清理 LiteSpeed「工具箱 → 清除 → 清除全部」及 Hostinger 已有整页缓存；若 Cloudflare 已启用页面缓存，也清除对应旧页面缓存。无需启用新的 CDN 或更换 DNS。
7. 在 LiteSpeed「缓存 → 排除 → 不缓存 URI」加入实际联系页路径：`/ianproject-contact/`。这是正式站目前的地址；以后改路径需同步更新。购物车／结算／账户通常由 WooCommerce 原生兼容排除，不额外更改缓存引擎。

## 安装后的简短验收

- 用无痕窗口：已定价商品加入购物车 → Contact；应出现正确型号、数量和金额。刷新后仍有清单。
- 新开另一个独立无痕会话／浏览器：空购物车不得显示上一个访客的商品。
- 未定价型号：Contact 带入所选型号和数量，不显示零价购买。
- 检查一个地板商品的计价单位和一个项目详情侧栏。产品卡片仍是三列、价格一行。
- 地板等延米商品显示 `/ metre`、MOQ `1 metre`，输入小于 1 的数量应被纠正；按套商品显示 `/ set`、MOQ `1 set`。延米仍允许 1.1、1.5 等大于起订量的小数数量。
- 检查邮箱／WhatsApp 草稿内容即可；仅在你决定发送时按发送。网站不会自动发送或保存表单联系资料。
- 安装后旧的搜索结果文字可能仍保留一段时间。Search Console 可对重点页面做实时检查／请求重新抓取，更新代码不等于 Google 立即更新摘要。

如果单位更新有误，可在工具中恢复对应商品的单位／MOQ 备份；重新预览后仍可查看上一次更新备份。若商品有后续人工编辑，停止自动恢复，避免覆盖新编辑。主题／扩展异常可恢复上一版并清缓存。不要用本地测试数据库覆盖正式站。
